== Project structure

- link:../src/bsp-tmpe627/doc/main.adoc[BSP Vivado project]: Board Support Package for TMPE-627. Includes ADC, DAC and XDMA communication and register configuration logic.
- link:../src/dsp/doc/main.adoc[DSP Vitis project]: HLS implementation of the data processing algorithm

The DSP must be compiled first to generate the IP containing the data processing logic. Then, the BSP can be compiled to generate all the communication and configuration logic around it. 

Therefore, to completely implement the project use the following command (the ``FWK_VIVADO_JOBS`` variable is used to use multiple cores when synthesizing).

[source,console]
....
make cfg=vitis build
FWK_VIVADO_JOBS=x make cfg=vivado build
....

The resulting bitfile can be found in ``out/TMPE-FWK_vivado/`` and can be loaded with Vivado. To open the Vivado project, use:

[source,console]
....
make cfg=vivado gui
....

In the same folder, the memory map files can be found, which will be required for ChimeraTK DeviceAccess.
