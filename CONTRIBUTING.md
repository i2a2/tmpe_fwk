# Contributing

Contributions are accepted under the Apache License, Version 2.0
([LICENSE](LICENSE)): by submitting, you grant the copyright and patent licenses
of Sections 2 and 3 and your contribution arrives under Apache-2.0, as stated in
Section 5. Please keep the per-file header used throughout this repository
(author, copyright, `SPDX-License-Identifier: Apache-2.0`) in every file you add
or modify.

## Files you may not contribute to under Apache-2.0

The nine files below carry the SPDX identifier `LicenseRef-TEWS-Reference-Design`.
They are copyright TEWS Technologies GmbH and are governed by TEWS's own terms
(reproduced in [NOTICE](NOTICE) and at the top of each file). Apache-2.0 does not
cover them, and no contribution can relicense someone else's copyright:

    src/bsp-tmpe627/cstr/tmpe627_pins.xdc
    src/bsp-tmpe627/cstr/tmpe627_timing.xdc
    src/bsp-tmpe627/cstr/tmpe627_implementation_timing.xdc
    src/bsp-tmpe627/cstr/tmpe62x_config.xdc
    src/bsp-tmpe627/src/ADC/adc.vhd
    src/bsp-tmpe627/src/ADC/adc_channel.vhd
    src/bsp-tmpe627/src/DAC/ad5754r.vhd
    src/bsp-tmpe627/src/DAC/dac.vhd
    src/bsp-tmpe627/src/DAC/pulse_stretcher.vhd

Do not edit these files in a pull request, and do not copy their contents into an
Apache-2.0 file: doing so would move TEWS-restricted source into the Apache-2.0
part of the repository. If a change to one of them is needed, open an issue
instead; the file is updated in place and keeps its TEWS header. TEWS's permission
covers use and redistribution of these files for academic and scientific purposes
with a TEWS TMPE627 only, so they must also keep their TEWS header verbatim.

## Vivado-generated files

`src/bsp-tmpe627/src/tmpe_daq_wrapper.vhd` carries
`LicenseRef-AMD-Xilinx-Output-Products`: it is wholly generated by Vivado 2021.1
(Create HDL Wrapper), so it has no `Apache-2.0` header and a contribution cannot
relicense it. Hand-editing it for a block-design change is a Vivado build step
(Create HDL Wrapper), not something a pull request should do.

Everything else in this repository is Apache-2.0 and is open to contributions.
The `fwk/` submodule is DESY's firmware framework; contribute to it upstream at
<https://gitlab.desy.de/fpgafw/fwk>.
